函式

本課學會：用函式（function）把一段程式包起來，需要時再呼叫。

先看範例

#include <iostream>

int square(int x) {
    return x * x;
}

void printLine(int n) {
    for (int i = 0; i < n; i++) {
        std::cout << "*";
    }
    std::cout << std::endl;
}

int main() {
    int result = square(5);
    std::cout << "5 的平方是 " << result << std::endl;
    printLine(3);
    printLine(6);
    return 0;
}
5 的平方是 25
***
******
其實你已經在用函式了：main 就是一個函式，程式從它開始執行。

逐行說明

  • int square(int x)：函式的樣子是「回傳型別 名稱(參數)」。最前面的 int 表示算完會交回一個整數，括號裡的 int x 是參數（parameter），也就是呼叫時要交給函式的材料。
  • return x * x;：把結果交回給呼叫的地方，函式也在這一行結束。
  • void：表示函式不交回任何值，只負責做事，例如 printLine 只印出星號。
  • square(5)：呼叫函式，5 會被放進 x，算出的 25 再存進 result。
  • 同一個函式可以呼叫很多次，printLine(3) 和 printLine(6) 共用同一段程式，只是參數不同。

常見錯誤

  • 把函式寫在 main 後面，編譯器會報 not declared in this scope。函式要先定義，才能被呼叫（先宣告的寫法之後會學）。
  • 有回傳型別的函式忘了 return，程式的結果不確定，編譯器通常也會給出警告。
  • 呼叫時參數的數量不對，例如 square() 或 square(1, 2)，會編譯失敗。

練習題

題目 1：寫一個函式 cube，回傳整數的三次方。

int cube(int x) { return x * x * x; }，呼叫 cube(3) 得到 27。

題目 2：寫一個函式 isEven，判斷整數是不是偶數。

bool isEven(int n) { return n % 2 == 0; }。bool 函式回傳 true 或 false，印出時顯示 1 或 0。

題目 3：寫一個函式 sumTo，回傳 1 加到 n 的總和。

在函式裡仿照上一課的迴圈：int sum = 0; for (int i = 1; i <= n; i++) { sum += i; } return sum;。sumTo(10) 得到 55。
