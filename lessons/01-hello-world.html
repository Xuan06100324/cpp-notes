Hello, World

本課學會：寫出、編譯並執行第一支 C++ 程式。

先看範例

#include <iostream>

int main() {
    std::cout << "Hello, World!" << std::endl;
    return 0;
}
Hello, World!

存成 main.cpp，用 g++ -std=c++17 main.cpp -o main 編譯，再執行 ./main。

逐行說明

  • #include <iostream>：引入輸入輸出功能，沒有它就不能用 std::cout。
  • int main()：程式從這裡開始執行，每支程式只有一個 main。
  • std::cout << ...：把右邊的內容送到螢幕。<< 可以想成「送往」。
  • std::endl：換行。
  • return 0;：告訴系統程式正常結束。

常見錯誤

  • 漏掉結尾的分號 ;，編譯器會在附近的行回報 error。
  • 寫成 cout 而沒有 std::，會出現 not declared 錯誤。
  • 字串用了中文引號 “ ”，必須是半形 " "。

練習題

題目 1：改成印出你的名字

把 "Hello, World!" 換成 "我是小明" 即可。

題目 2：印出兩行文字

連續寫兩個 std::cout 敘述，各自以 std::endl 結尾。
