變數與資料型別

本課學會：宣告變數（variable），並選擇正確的型別（type）。

先看範例

#include <iostream>
#include <string>

int main() {
    int age = 20;
    double height = 172.5;
    char grade = 'A';
    bool passed = true;
    std::string name = "小明";

    std::cout << name << " " << age << " 歲" << std::endl;
    std::cout << "身高 " << height << "，等級 " << grade
              << "，通過 " << passed << std::endl;
    return 0;
}
小明 20 歲
身高 172.5，等級 A，通過 1

逐行說明

  • int：整數。double：有小數的數字。
  • char：單一字元，用單引號 'A'。
  • bool：只有 true 或 false，印出時會顯示 1 或 0。
  • std::string：文字，需要 #include <string>，用雙引號。
  • 宣告格式：型別 名稱 = 初始值;

常見錯誤

  • 用 int 存小數，例如 int x = 3.9; 會變成 3，小數被直接捨去。
  • 變數沒給初始值就使用，結果不確定。
  • 單引號與雙引號混用：char c = "A"; 會編譯失敗。

練習題

題目 1：宣告變數記錄你的年齡與身高並印出

年齡用 int，身高用 double，再用 std::cout 印出。

題目 2：int n = 7 / 2; 的結果是多少？
