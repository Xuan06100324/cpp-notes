運算符

本課學會：用運算符做計算與比較。

先看範例

#include <iostream>

int main() {
    int a = 7, b = 2;
    std::cout << a + b << std::endl;   // 加
    std::cout << a - b << std::endl;   // 減
    std::cout << a * b << std::endl;   // 乘
    std::cout << a / b << std::endl;   // 整數除法
    std::cout << a % b << std::endl;   // 餘數
    std::cout << 7 / 2.0 << std::endl; // 有小數的除法
    std::cout << (a > b) << " " << (a == b) << std::endl;
    return 0;
}

先記住：/ 看「兩邊是不是整數」，兩邊都是整數就是整數除法。

逐行說明

  • /：兩個整數相除，結果還是整數，小數會被捨去，所以 7 / 2 是 3。
  • %：取餘數，7 % 2 是 1，常用來判斷奇偶數。
  • 7 / 2.0：只要有一邊是小數，結果就會保留小數。
  • >、==：比較運算，成立印出 1（true），不成立印出 0（false）。

常見錯誤

  • 把 ==（比較）寫成 =（指定），意思完全不同，後面會造成錯誤判斷。
  • 以為 7 / 2 會是 3.5，其實是 3。
  • 除以 0 會讓程式出錯，計算前要先確認除數不是 0。

練習題

題目 1：10 % 3 是多少？

1。10 除以 3 商 3 餘 1。

題目 2：怎麼讓 5 / 2 得到 2.5？

改成 5 / 2.0 或 5.0 / 2。

題目 3：怎麼判斷整數 n 是偶數？

n % 2 == 0 成立就是偶數。
