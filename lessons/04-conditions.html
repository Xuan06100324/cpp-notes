條件判斷

本課學會：用 if / else 讓程式依條件做不同的事。

先看範例

#include <iostream>

int main() {
    int score = 75;

    if (score >= 90) {
        std::cout << "優等" << std::endl;
    } else if (score >= 60) {
        std::cout << "及格" << std::endl;
    } else {
        std::cout << "不及格" << std::endl;
    }
    return 0;
}
及格
想同時判斷兩個條件，可以用 &&（而且）與 ||（或者），之後的練習會用到。

逐行說明

  • if (條件)：條件成立才執行大括號裡的內容。
  • else if：前面都不成立時，再檢查下一個條件。
  • else：以上都不成立時執行。
  • 程式由上往下檢查，遇到第一個成立的就停止，不會再看後面。

常見錯誤

  • 條件寫成 if (score = 60)，單個 = 是指定，應該用 ==。
  • 條件順序顛倒：先寫 score >= 60 再寫 >= 90，90 分也會被判成「及格」。
  • if (x > 1) 後面直接加分號，會讓大括號裡的內容永遠執行。

練習題

題目 1：把 score 改成 95，會印出什麼？

優等。

題目 2：寫出判斷「年齡大於等於 18」就印出「成年」的程式。

if (age >= 18) { std::cout << "成年"; }
