迴圈

本課學會：用 for 與 while 讓程式重複執行。

先看範例

#include <iostream>

int main() {
    for (int i = 1; i <= 5; i++) {
        std::cout << i << " ";
    }
    std::cout << std::endl;

    int sum = 0;
    int n = 1;
    while (n <= 100) {
        sum += n;
        n++;
    }
    std::cout << "1 到 100 的總和是 " << sum << std::endl;
    return 0;
}
1 2 3 4 5 
1 到 100 的總和是 5050

逐行說明

  • for (起始; 條件; 變化)：知道要跑幾次時用。i++ 就是 i 加 1。
  • while (條件)：條件成立就一直重複，適合不確定跑幾次的情況。
  • sum += n：等於 sum = sum + n，把 n 累加進 sum。
  • n++ 讓條件總有一天不成立，否則迴圈永遠停不下來。

常見錯誤

  • while 裡忘了更新 n，造成無窮迴圈，可以按 Ctrl+C 強制停止。
  • for 的條件寫成 i < 5，只會印到 4，少跑一次。
  • 在迴圈裡重新宣告累加變數，每圈都會被歸零。

練習題

題目 1：用 for 印出 1 到 10。

for (int i = 1; i <= 10; i++) std::cout << i << " ";

題目 2：算出 1 到 10 的總和。

仿照範例的 while，把條件改成 n <= 10，答案是 55。
